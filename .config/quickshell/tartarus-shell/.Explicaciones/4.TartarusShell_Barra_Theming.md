# Checkpoint — TartarusShell: Barra completamente tematizada

**Estado:** funcional.

## Objetivo de este checkpoint

Migrar la barra de TartarusShell y sus componentes principales al sistema global de:

- `Color.qml` para roles cromáticos semánticos.
- `Style.qml` para design tokens reutilizables.

La meta es eliminar colores hardcodeados y reducir valores visuales locales cuando exista un token global apropiado, sin mezclar theming con lógica funcional.

## Componentes migrados

```text
bar/
├── Bar.qml
└── components/
    ├── ActiveWindow.qml
    ├── Audio.qml
```

## Arquitectura visual

La barra ahora consume el sistema global:

```text
                 Color.qml
                    │
      ┌─────────────┼─────────────┐
      ↓             ↓             ↓
     Bar         Network       Audio
      ↓             ↓             ↓
 Workspaces     Popup         SystemTray
      ↓
ActiveWindow
      ↓
Clock
```

Y en paralelo:

```text
                 Style.qml
                    │
      ┌─────────────┼─────────────┐
      ↓             ↓             ↓
    radius        spacing       padding
      ↓             ↓             ↓
   Bar UI        tray/items    popups/items
```

## `Bar.qml`

El fondo principal pasó de un color hardcodeado:

```qml
color: "#202020"
```

a:

```qml
color: Color.background
```

El spacing de la zona derecha pasó de:

```qml
spacing: 8
```

a:

```qml
spacing: Style.spacingSmall
```

La altura de la barra sigue local:

```qml
implicitHeight: 40
```

### Decisión de diseño

No se movió `barHeight` a `Style.qml` porque es una dimensión específica del módulo Bar, no un design token global.

## `NetworkPopup.qml`

Se migraron:

```text
fondo
radius
padding
spacing
texto principal
texto secundario
estado conectado
```

Ejemplos:

```qml
color: Color.surface
radius: Style.radiusMedium
```

Cada red conectada usa:

```qml
color: modelData.connected
    ? Color.selection
    : "transparent"
```

El nombre usa:

```qml
Color.foreground
```

La intensidad de señal usa:

```qml
Color.foregroundMuted
```

### Decisión de diseño

`implicitWidth: 280` permanece local porque describe específicamente el popup de red.

## `Network.qml`

Se migraron:

```text
hover
radius
padding horizontal
foreground
estado offline
```

Hover:

```qml
color: mouseArea.containsMouse
    ? Color.surfaceHover
    : "transparent"
```

Texto:

```qml
color: root.connectedDevice
    ? Color.foreground
    : Color.foregroundMuted
```

El estado offline no utiliza `Color.error`, porque estar desconectado es un estado válido y no necesariamente un error.

## `Audio.qml`

La lógica de PipeWire permanece intacta.

Se migraron:

```text
hover
radius
padding
foreground
estado muted
```

Hover:

```qml
Color.surfaceHover
```

Texto normal:

```qml
Color.foreground
```

Muted / sink no disponible:

```qml
Color.foregroundMuted
```

### Decisión de diseño

`Muted` no usa `Color.error`, porque mute es una acción válida del usuario.

La lógica de:

```text
click → mute/unmute
scroll → volumen ±5%
```

no se modificó.

## `SystemTray.qml`

Se migraron:

```text
spacing
radius
hover
```

Ejemplos:

```qml
spacing: Style.spacingSmall
radius: Style.radiusSmall
color: mouseArea.containsMouse
    ? Color.surfaceHover
    : "transparent"
```

Se conservaron intactos:

```text
SystemTray.items
QsMenuAnchor
click izquierdo
click derecho
click central
tooltip

```

### Limpieza

Los `console.log()` usados para verificar scroll pueden eliminarse una vez confirmado el forwarding.

### Pendiente

El `ToolTip` de `QtQuick.Controls` todavía usa el estilo de Qt Controls y no está tematizado por `Color.qml`.

## Roles semánticos usados en la barra

Actualmente la barra consume principalmente:

```text
Color.background
Color.surface
Color.surfaceHover
Color.selection
Color.foreground
Color.foregroundMuted
```

Esto evita depender de nombres específicos de una paleta.

Ejemplo:

```text
Workspaces.qml
    ↓
Color.selection
    ↓
Catppuccin / Tokyo Night / futura paleta
```

## Tokens de Style usados

```text
Style.radiusSmall
Style.radiusMedium
Style.spacingSmall
Style.paddingSmall
Style.paddingMedium
```

No todos los números locales fueron migrados.

### Regla adoptada

Un valor pasa a `Style.qml` cuando representa una decisión visual reutilizable.

Valores específicos de un componente pueden permanecer locales.

Ejemplos que permanecen locales:

```text
Bar implicitHeight = 40
NetworkPopup width = 280
algunas alturas compactas específicas
tray item size = 28
tray icon size = 18
```

## Cambio de paleta

La barra responde al mismo sistema de hot reload ya validado en el launcher.

Flujo:

```text
python scripts/theme.py set <palette>
        ↓
active-theme.json
        ↓
Color.qml
        ↓
Bar + componentes
```

Por tanto, cambiar entre:

```text
Catppuccin Mocha
Tokyo Night Storm
```

actualiza también la barra sin reiniciar Quickshell.
